Replit Agent Follow-Up Instruction: Update HookahDolls Color Scheme and Sitewide Accent Styling

Do not rebuild the platform. Only update the sitewide color scheme, theme tokens, buttons, cards, navigation, badges, feed elements, and accent colors.

The HookahDolls logo uses red, but red should not be the dominant UI color because too much red can feel harsh, aggressive, urgent, or tiring during long browsing sessions.

Use red only as a brand accent.

The site should feel like a modern social media platform with a premium hookah lounge style.

Design goal:

HookahDolls should feel social, clean, premium, easy to browse, and not overly dark or overly red.

Use this color system across the site:

Primary Background:

* `#0F1115`
* Use for main page backgrounds.
* This is softer than pure black and easier on the eyes.

Secondary Background:

* `#171A21`
* Use for sidebars, nav panels, dashboard panels, and feed sections.

Card Background:

* `#1F232B`
* Use for posts, membership cards, profile cards, modals, pricing cards, and dashboard cards.

Elevated Card Background:

* `#262B35`
* Use for hover states, active cards, dropdowns, and highlighted panels.

Border Color:

* `#343A46`
* Use for subtle card borders, dividers, input borders, and sidebar separation.

Primary Text:

* `#F5F7FA`
* Use for main headings and important text.

Secondary Text:

* `#C7CBD3`
* Use for body copy, descriptions, subtitles, and less important labels.

Muted Text:

* `#8E95A3`
* Use for timestamps, metadata, placeholder text, and inactive labels.

Primary Accent:

* Champagne Gold: `#D6B56D`
* Use for premium buttons, upgrade buttons, selected tabs, badges, highlights, and important calls to action.

Secondary Accent:

* Social Blue: `#1877F2`
* Use for social actions such as Follow, Add Friend, Message, Create Profile, and Explore Feed.

Brand Red:

* `#E11931`
* Use only for small brand accents, logo support, alerts, notification dots, active live indicators, and very limited CTA accents.
* Do not use red as the main background.
* Do not use red for large buttons across the whole site.
* Do not use red for large page sections.

Success / Online:

* `#31C48D`
* Use for online status dots, successful payments, verified success messages, and active status.

Warning:

* `#F59E0B`
* Use for pending verification, pending review, low credits, and caution messages.

Error:

* `#EF4444`
* Use for form errors, failed payments, rejected content, and admin warnings.

Premium Purple:

* `#8B5CF6`
* Use sparingly for VIP, Platinum, special promotions, and exclusive content.

Rose Accent:

* `#E85D75`
* Use sparingly for Doll-specific highlights, creator badges, and soft decorative accents.

Sitewide Design Rules

1. Do not make the site red-heavy.
2. Do not use pure black as the only background.
3. Do not use bright red for all buttons.
4. Use blue for normal social actions.
5. Use gold for premium actions.
6. Use red only for brand details and alerts.
7. Keep the site scroll-friendly and easy on the eyes.
8. Make the interface feel like a premium social network, not a warning screen or adult-only paywall.

Accessibility Requirements

Make sure text contrast is readable.

Avoid:

* Red text on black backgrounds for body copy
* Red buttons everywhere
* Low-contrast gray text
* Neon red backgrounds
* Large red page sections

Use red only where it has a clear purpose.

Design Inspiration

Use the usability style of major social media platforms:

* Blue for social interaction and trust
* Neutral backgrounds for long browsing
* Clear cards and feed layout
* Subtle dividers
* Easy-to-read text
* Accent colors used intentionally

But keep HookahDolls unique with:

* Dark lounge atmosphere
* Smoke-inspired gradients
* Gold premium elements
* Red logo accent
* Rose highlights for Doll-related features

Final Result

The site should feel like:

* A social network first
* Premium hookah lounge second
* Creator monetization platform third

Users should not feel overwhelmed by red or feel like the site is pay-only. The color system should make free social features feel accessible and paid features feel premium.
