Replit Agent Follow-Up Instruction: Upgrade Create a Free Profile Workflow

Do not rebuild the HookahBuddys platform. Only upgrade the existing `/choose-membership` and “Create a Free Profile” signup workflow.

Use the platform name:

HookahBuddys

Important:

Any button labeled “Create a Free Profile,” “Become a Buddy,” “Join Free,” “Start Free,” or similar should still route to:

`/choose-membership`

The `/choose-membership` page should become a guided signup wizard instead of immediately showing all plans at once.

Core Goal

When a user clicks “Create a Free Profile” or “Become a Buddy,” the first question should be:

“Are you a Male Buddy or Female Buddy?”

Then the flow should branch based on the user’s answer.

Workflow Overview

Step 1:

Ask:

“Are you a Male Buddy or Female Buddy?”

Options:

1. Male Buddy
2. Female Buddy

No option should be preselected.

The user must select one before continuing.

If the user selects Male Buddy, continue to the Male Buddy membership upgrade flow.

If the user selects Female Buddy, continue to the Female Buddy Creative Buddy upgrade flow.

Important correction:

Use “Male Buddy,” not “Make Buddy.”

Final Goal

The Create a Free Profile workflow should feel guided, simple, and free-first.

The user clicks Create a Free Profile, chooses Male Buddy or Female Buddy, then sees only the upgrade path that makes sense for that choice.

Male Buddy users can stay free, upgrade to Silver/Gold/Platinum, or optionally buy credits after choosing Stay Free.

Female Buddy users can stay free or upgrade to Creative Buddy for `$24.99/month`.

All paths eventually lead to the standard signup form and then payment only if the user selected a paid option.
