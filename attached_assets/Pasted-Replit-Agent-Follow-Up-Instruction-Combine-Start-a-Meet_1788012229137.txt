Replit Agent Follow-Up Instruction: Combine “Start a Meetup” and “Plan Event” Into One Creation Flow

Do not rebuild the HookahBuddys platform. Only update the existing Meetup creation flow.

Current issue:

After a member creates a Meetup, the system shows an option/button to “Plan Event.”

This is incorrect.

Creating a Meetup should already include planning the event. Starting a Meetup and planning the event should be one combined process, not two separate tasks.

Required change:

When a member clicks “Start a Meetup,” the form should collect all Meetup and event details in one creation flow.

Remove the separate post-creation “Plan Event” step.

Core Rule

Starting a Meetup = planning the event.

A Meetup should not be created as an empty shell that requires a second “Plan Event” button afterward.

The Start a Meetup form should ask for:

* Meetup title
* Description
* Date
* Start time
* End time
* Event type
* Venue/location
* Online link, if applicable
* Host/organizer
* RSVP settings
* Attendee limit
* Invite options
* Privacy
* Free or paid status
* Cover image
* Tags/categories
* Rules/notes

All of this should be part of the initial Start a Meetup process.

Routes

Keep or use the existing route:

/meetups/create

The page title should be:

“Start a Meetup”

Subtitle:

“Create your Meetup with the event details, date, time, location, RSVP settings, and invite options all in one step.”

Do not use a separate required route such as:

/meetups/:id/create-event

unless it is only used internally or for creating additional future events. It should not be shown immediately after initial Meetup creation.

Remove / Replace “Plan Event” Language

Search the project for:

* “Plan Event”
* “Plan Your Event”
* “Create Event”
* “Add Event”
* “No events yet”
* “Plan your first event”
* “This Meetup has no events”

Remove or replace this language where it appears after Meetup creation.

Use replacement labels:

* “Edit Meetup”
* “Manage Meetup”
* “Manage RSVPs”
* “Invite Friends”
* “Share Meetup”
* “Create Another Meetup”
* “Duplicate Meetup”

Do not show “Plan Event” as the next required action after creating a Meetup.
