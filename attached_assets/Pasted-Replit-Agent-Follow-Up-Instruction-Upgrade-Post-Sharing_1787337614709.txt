Do not rebuild the HookahBuddys platform. Only upgrade the existing post system to support sharing other members’ posts.

Add a Facebook-style Share feature to posts so members can share eligible posts:

* Publicly
* Privately
* To The Lounge / Feed

* To Groups
* By copying a link

Use the platform name HookahBuddys.

Do not remove or replace:

* The Lounge

* Events
* Member profiles
* Doll/Bro profiles

Only add post sharing.

Core Feature

Add a Share icon/button to all eligible posts.

The Share button should appear in the post action row next to:

* Like
* Comment
* Share
* Save

When a member clicks Share, open a Share modal.

Share Modal

The Share modal should include:

Title:

“Share Post”

Show the original post preview, including:

* Original author profile photo
* Original author display name
* Original author badge if applicable
* Original post text preview
* Original image/video thumbnail if applicable
* Original timestamp
* Original post category
* Link to original post

Add optional comment field:

“Say something about this post…”

Add sharing options:

1. Share Publicly
2. Share Privately
3. Share to The Lounge
4. Share with Friends
5. Share to Group
6. Copy Link

Share Option 1: Share Publicly

When selected:

* Create a shared post with audience set to `public`.
* The shared post should be visible to all users who can access public content.
* The shared post should appear on the sharing user’s public profile Posts tab.
* The shared post may also appear in The Lounge / public feed depending on the feed algorithm.
* The shared post should show the sharing user’s optional comment above the original shared post preview.

Button label:

“Share Publicly”

Audience badge:

“Public”

Important rule:

Only allow public sharing if the original post is public and the original author allows public sharing.

Do not allow friends-only, private, locked, premium, or private Group content to be shared publicly.

Share Option 2: Share Privately

When selected:

* Allow the member to privately share the post with one or more selected members or friends.
* Show a searchable recipient selector.
* User can select:

  * Friends
  * Followers/following if messaging privacy allows
  * Specific members by username
* Create a private share message or private shared post notification.
* The shared post should not appear in The Lounge.
* The shared post should not appear publicly on the sharing user’s profile.
* The shared post should only be visible to the selected recipients.
* Recipients should receive a notification or private message with the shared post preview.

Button label:

“Share Privately”

Audience badge:

“Private”

Private share message should include:

* Sharing user name
* Optional comment
* Original post preview
* View Post button

If the recipient does not have permission to view the original post, show:

“This post is private or no longer available.”

Important rule:

Private sharing still must respect the original post’s privacy. Private sharing should not allow users to bypass privacy, premium content locks, Group privacy, or blocked-user rules.

Share Option 3: Share to The Lounge

When selected:

* Create a new shared post in The Lounge feed.
* Audience should be public by default.
* Show the member’s optional comment above the original shared post preview.
* Shared post should appear in The Lounge feed.
* Respect the original post’s sharing permissions.

Button label:

“Share to The Lounge”

Audience badge:

“The Lounge”

Important rule:

Only public posts should be shareable to The Lounge.

Share Option 4: Share with Friends

When selected:

* Create a shared post visible to accepted friends only.
* Audience should be set to `friends`.
* The shared post should appear in friends’ feeds and on the sharing user’s profile only for friends.
* Do not show this shared post to non-friends or the general public.

Button label:

“Share with Friends”

Audience badge:

“Friends”

Important rule:

Friends-only posts can only be shared with friends if the original author allows it.

Share Option 5: Share to Group

When selected:

* Show a dropdown or searchable list of Groups the user belongs to.
* Only show Groups where the user has permission to post.
* Allow the user to choose one Group at a time for now.
* Create a shared Group post inside that Group.
* Show the member’s optional comment above the original shared post preview.

Button label:

“Share to Group”

Audience badge:

“Group”

Group rules:

* If the Group requires post approval, set shared post status to `pending_review`.
* If member posting is disabled, do not allow sharing.
* If the member is muted, limited, or banned, do not allow sharing.
* If the Group is private, the shared post must stay inside that Group.
* Private Group posts cannot be shared outside the original private Group.

Share Option 6: Copy Link

When selected:

* Copy a direct post URL to the user’s clipboard.
* Show confirmation:

“Post link copied.”

If the post is private or restricted, users without permission should see:

“This post is private or no longer available.”

Button label:

“Copy Link”

Privacy and Sharing Rules

Respect all privacy rules.

Do not allow sharing when:

* The original post is deleted
* The original post is removed
* The original post is hidden by admin
* The original post is pending moderation
* The original post is from a private Group and the user is trying to share it outside that Group
* The original post is friends-only and the user is trying to share it publicly
* The original post is private and the user is trying to share it publicly
* The original post contains premium Doll content
* The original post contains locked paid content
* The original post is subscription-only content
* The original post contains private video chat content
* The original post contains private messages
* The original author has disabled sharing
* The user has blocked the original author
* The original author has blocked the user

Premium Content Rule

Do not allow members to share locked premium Doll photos, premium videos, paid content, paid messages, subscription-only content, private video chat content, verification content, or admin-only content.

If a post contains premium or restricted content, show:

“This content cannot be shared because it includes premium or restricted content.”

Private Group Rule

Posts from private Groups can only be shared inside the same private Group if allowed by Group settings.

Private Group posts cannot be shared to:

* Public feed
* The Lounge
* Friends outside the Group
* Other Groups
* Public profiles
* Copy link access for non-members

Friends-Only Rule

If a post is friends-only, allow resharing only to friends if the original author allows sharing.

Do not allow friends-only posts to be shared publicly.

Private Share Rule

Private sharing should send the post only to selected recipients.

Private sharing should not create a public feed post.

Private sharing should not expose the original post if the recipient does not have permission to view it.
