Replit Agent Prompt: Build HookahDolls.com Platform

Build a full-stack web platform for HookahDolls.com, a hookah-themed social and creator platform where verified women creators called “Dolls” create hookah-centered profiles and content, and paying members called “I Love Dolls” browse, subscribe, message, unlock content, and request private video chats.

This is not a traditional dating site. It is a hookah-centered creator/social platform. The hookah theme is mandatory across the entire user experience. Every Doll profile, upload, verification item, premium media item, short video, featured card, and live/video chat session must include a visible hookah. Content without a visible hookah must be rejected or held for admin moderation.

Build the platform with a polished, modern, premium nightlife/lounge aesthetic. Use dark backgrounds, smoke-inspired gradients, gold or rose-gold accents, glassmorphism cards, rounded UI, and strong mobile responsiveness.

Recommended Tech Stack

Use:

React / Vite frontend
Node.js / Express backend
PostgreSQL database
Prisma ORM
Stripe for payments
JWT/auth sessions
Role-based access control
File uploads for images/videos
Admin moderation workflow
Placeholder integration structure for video chat, such as Daily.co, Twilio Video, or LiveKit
Cloud storage-ready architecture for media uploads

Do not hardcode everything as static pages. Build a real app structure with routes, reusable components, database models, authentication, dashboards, and admin controls.
