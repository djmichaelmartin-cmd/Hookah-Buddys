Credit Packages
Package	Price	Cost Per Credit	Positioning

VIP Pack	$99.99	1,600 credits	Best value

This keeps the average credit value around $0.06–$0.10 per credit, with better value for larger purchases.

Message Credit Pricing
Sending Messages to Dolls
Action	Credits
Send first message to a Doll	20 credits
Send follow-up message	10 credits
Send photo attachment	25 credits
Priority message	50 credits

Recommended default:

Members need 20 credits to start a new conversation with a Doll, then 10 credits per additional message.

Why this works: It prevents spam, creates real monetization, and makes first contact valuable without being too expensive.

Video Chat Credit Pricing
Private Video Chat
Session Type	Credits	Approx. Dollar Value
5-minute intro chat	150 credits	~$9–$15
10-minute private chat	275 credits	~$17–$27
15-minute private chat	400 credits	~$25–$40
30-minute private chat	750 credits	~$47–$75
Per-minute extension	30 credits/minute	~$1.80–$3/min

Recommended default:

Private video chat costs 30 credits per minute, with a 5-minute minimum.

So the minimum video chat session is:

5 minutes = 150 credits

This is clean, easy to understand, and scalable. Dolls can eventually set their own rates, but the platform should launch with standard pricing.

This gives Dolls a strong reason to participate while keeping the platform profitable.
