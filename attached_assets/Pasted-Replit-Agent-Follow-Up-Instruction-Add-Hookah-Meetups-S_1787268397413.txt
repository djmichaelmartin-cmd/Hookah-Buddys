Members should be able to create Meetups similar to Meetup.com.

A Meetup is a local or interest-based gathering hub centered around hookah culture.

Important Logic

On Meetup.com, events are tied to groups rather than existing as isolated standalone items. For HookahBuddys, use the same structure:

A Meetup can create Events.

When a member creates an Event from inside a Meetup:

The Event should appear inside that Meetup.
The Event should also appear on the global /events page.
The Event should be searchable and filterable by location, date, category, and interest.
The Event should show which Meetup is hosting it.

Global Event Sync

When a Meetup Event is created, updated, cancelled, or deleted, sync it to the global Events system.

Rules:

Published Meetup Events appear on /events.
Draft Meetup Events do not appear on /events.
Cancelled Meetup Events remain visible only if admin/organizer setting allows.
Private Meetup Events appear only to approved Meetup members.
Public Meetup Events appear in global Events discovery.
Online Meetup Events may appear outside local radius.
In-person Meetup Events should use local radius search.
